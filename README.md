# 코믹파티 DCE 한글패치 1.01

Windows용 일본어 **코믹파티 DCE 본편**에 설치하는 한글패치입니다. 본편은 별도로 필요합니다.

## 다운로드와 설치

1. [최신 릴리스](https://github.com/adios1579-lgtm/Comipa-DCE-Korean-Patch/releases/latest)에서 **Comipa_DCE_Korean_Patch_1.01.zip**을 받습니다.
2. 게임을 종료하고, `ComiPaRT.exe`가 있는 폴더에 압축을 전부 풉니다.
3. **한글패치_설치.exe**를 실행합니다. 원본을 확인하고 패치 파일을 생성하므로 몇 분 걸릴 수 있습니다.
4. 설치 후 **코믹파티_DCE_한글판.exe**로 실행합니다.

Python이나 별도 압축 프로그램을 설치할 필요는 없습니다. Windows 10/11 64비트와 .NET Framework 4.5 이상이 필요합니다. GitHub의 `Source code` 압축은 설치 파일이 아닙니다.

## 1.01 변경 사항

- 대사 42곳의 ‘가슈’를 ‘갓슈’로 수정
- 기존 1.00 대본의 저장 위치와 글자 배치를 유지

## 포함된 내용

- 스토리 모드 한글화와 기존 통합 콘텐츠
- 최신 대사·메모 수정, CG 85장 한글화 통합
- CD 없이 실행하는 수정
- 실행 시 자동 업데이트 확인과 별도 수동 업데이트 실행기

## 업데이트

실행기는 새 버전과 변경 내용을 보여 주고 동의를 받은 뒤 업데이트합니다. 거절하거나 인터넷 연결 확인에 실패하면 정상 설치된 현재 게임을 실행합니다.

**한글패치_업데이트.exe**는 업데이트만 확인·적용합니다. 게임을 임의 실행하지 않습니다. 게임이 실행 중이면 먼저 종료해 주세요.

세이브·CG 해금 기록(`cpdata.*`)과 개인 설정은 업데이트 대상에 포함하지 않습니다. 사용자가 개별 수정한 파일은 덮어쓰지 않고 안내합니다. 업데이트 중 교체가 실패하면 이전 상태로 복구하며, 중단된 작업은 다음 실행 때 복구합니다.

`.story_orig` 파일은 다음 패치 생성에 필요한 원본 보관 파일이므로 삭제하지 마세요. 지원 파일 시스템에서는 하드링크를 사용합니다. 임시 다운로드와 교체 이전본은 정상 완료 후 정리합니다.

**1.00 설치 이용자는 기존 `한글패치_업데이트.exe`로 업데이트하세요.** 새 전체 ZIP을 기존 업데이트 파일 위에 먼저 풀지 마세요.

자동 업데이트 실행기가 없는 최종 0.80 통합본은 [1.00 설치본](https://github.com/adios1579-lgtm/Comipa-DCE-Korean-Patch/releases/tag/v1.0.0)으로 등록한 뒤 수동 업데이트하세요. 그 밖의 구버전은 해당 설치기로 원상복구한 뒤 1.01 전체 설치본을 사용하세요.

오류 기록은 `updates/last-check.txt`에 있습니다. 복구가 실패했다면 `.comipa-update` 폴더를 보존해 주세요.

표시 버전은 **1.01**, 자동 업데이트용 내부 버전과 태그는 `1.1.0` / `v1.1.0`입니다.
