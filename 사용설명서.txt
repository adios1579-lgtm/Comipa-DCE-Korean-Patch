코믹파티 DCE 한글패치 1.03

처음 설치
1. Windows용 일본어 코믹파티 DCE 본편을 준비하고 게임을 종료합니다.
2. Comipa_DCE_Korean_Patch_1.03.zip을 ComiPaRT.exe가 있는 폴더에 전부 풉니다.
3. 한글패치_설치.exe를 실행해 설치합니다. 원본 판본을 확인하고 한글패치 파일을 생성하므로 몇 분 걸릴 수 있습니다.
4. 이후 코믹파티_DCE_한글판.exe로 실행합니다.

최신 한글패치는 실행할 때 확인하며, 새 버전이 있으면 변경 내용을 보여 주고 동의를 받습니다.
업데이트를 거절하거나 인터넷 연결이 안 되면 정상 설치된 현재 게임을 실행합니다.
한글패치_업데이트.exe는 업데이트만 확인·적용하며 게임을 실행하지 않습니다.
게임 실행 중에는 업데이트할 수 없습니다. 게임을 종료한 뒤 수동 업데이트를 실행해 주세요.

1.03 변경 사항
- 이전 플레이의 자동 선택 기록이 새 게임에 남아 이쿠미 필수 분기를 놓치던 문제 수정.
- 새 게임·날짜 변경 때 반복 선택 기록을 초기화하고 같은 날 반복 선택·저장 복원은 유지.
- 기존 대사·이미지·저장 배치는 그대로 유지.
- 이미 놓친 필수 이벤트를 자동으로 되돌리지는 않으므로 해당 분기 이전 저장 파일에서 이어 하거나 새 게임을 시작하세요.

포함 내용
- 스토리 모드 한글화와 기존 통합 콘텐츠, 최신 대사·메모 수정
- CG 85장 한글화 통합
- CD 없이 실행하는 수정
- 자동/수동 업데이트, 파일 검사, 교체 실패 복구

보존되는 파일
cpdata.* 세이브·CG 해금 기록, 개인 환경설정은 업데이트 대상이 아닙니다.
각 대상 파일의 .story_orig는 다음 업데이트에서 패치 파일을 재생성하는 데 필요한 원본 보관 파일입니다. 삭제하지 마세요.
지원되는 파일 시스템에서는 원본과 하드링크로 연결해 불필요한 복사를 줄입니다.
원본 게임 전체나 세이브를 복제하지 않습니다. 업데이트 중 임시 이전본은 성공 후 삭제합니다.

기존 패치 이용자
1.00·1.01·1.02 설치 이용자는 기존 한글패치_업데이트.exe로 업데이트하세요. 새 전체 ZIP을 먼저 덮어 풀지 마세요.
실행기가 없는 최종 0.80 통합본은 공개된 1.00 설치본으로 등록한 뒤 수동 업데이트하세요.
다른 버전/개별 수정으로 판별되는 파일은 덮어쓰지 않습니다.
구버전은 해당 구버전 설치기의 원상복구 기능을 사용한 뒤 1.03 버전을 설치해 주세요. 세이브는 유지됩니다.
설치 후 실행은 코믹파티_DCE_한글판.exe를 사용하세요. ComiPaRT.exe를 직접 실행하면 업데이트 확인을 건너뜁니다.

오류 발생
손상·알 수 없는 변경·필수 파일 누락은 자동으로 덮어쓰지 않습니다.
업데이트 도중 종료됐다면 실행기에서 복구합니다. 복구가 실패한 경우 .comipa-update 폴더를 보존해 주세요.
검사 결과는 updates/last-check.txt에 기록됩니다.

필요 환경: Windows 10/11 64비트, .NET Framework 4.5 이상. Python·컴파일러 설치는 필요하지 않습니다.
본편은 별도 필요합니다. GitHub의 Source code 압축은 패치 설치 파일이 아닙니다.
